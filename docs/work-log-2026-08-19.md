## 現在の会話フロー

1. 参加者と期間を自然文で指定する。
2. 参加者全員の共通空き時間と、各時間に利用可能な設備を読み取る。
3. Web Consoleに候補を日付単位で折り畳める表として表示する。
4. 候補行で設備とメール送信有無を選び、「選択する」を押す。
5. AgentがDeskNet'sの予定追加画面へ日時、参加者、設備、メール設定を入力する。
6. 議題がプロンプトにあれば転記し、なければ空欄にする。
7. DeskNet's専用Edgeを最前面に表示する。
8. ユーザーが内容を確認し、DeskNet's上の「追加」を手動で押す。

## Local起動手順

### Terminal 1: Agent API

```powershell
$env:ALLOWED_DOMAINS = "desknets.midac.jp"
npm run dev:api
```

### Terminal 2: Web Console

```powershell
npm run dev:web
```

URL：`http://127.0.0.1:3000`

### Terminal 3: DeskNet's専用Edge

```powershell
npm run auth:desknets -- "https://desknets.midac.jp/dneo/dneo.cgi?cmd=schindex#cmd=schweekgrp"
```

- 専用Edgeで手動ログインする。
- スケジュール画面を開いたままにする。
- DeskNet'sタブは1枚だけにする。
- Terminal 3と専用EdgeをRun中に閉じない。
